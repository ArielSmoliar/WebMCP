# Challenge Work

Captain's Table was created in this dedicated repository for the OpenAI WebMCP
Challenge. The repository began after the challenge start date.

The product concept and implementation are new. General domain experience from
our earlier Offsite Captain work informed the scenario, but no prior application
code or interface was copied into this repository.

Challenge-specific work includes:

- The shared human and browser-agent decision surface.
- Six state-aware WebMCP tools and their dynamic lifecycle.
- The page-only exact-plan authorization boundary.
- Stale-state invalidation, revision calibration, and protocol evidence.
- SQLite session persistence and idempotent simulated execution.
- The design system, interaction plan, tests, deployment configuration, and docs.
