# Test Plan

Generated by the engineering plan review on 2026-08-31.
Branch: `main`
Repository: Captain's Table WebMCP demo

## Affected Pages and Routes

- `/`: full shared decision surface, protocol evidence, authorization, and receipt.
- `/api/session` and `/api/session/{id}`: session creation and recovery.
- `/api/session/{id}/diagnose`: conflict diagnosis and revision enforcement.
- `/api/session/{id}/repairs`: bounded alternative generation.
- `/api/session/{id}/selection`: exact-plan mutation and stale-state handling.
- `/api/session/{id}/constraint`: bounded arrival edit and authorization invalidation.
- `/api/session/{id}/revert`: bounded pre-authorization reversal with a new revision.
- `/api/session/{id}/authorize`: direct-UI consent and exact-plan authorization.
- `/api/session/{id}/execute`: authorized idempotent execution and receipt recovery.
- `/healthz` and `/readyz`: process and persistent-storage health.

## Key Interactions to Verify

- ChatGPT discovers and invokes the state-appropriate WebMCP tools.
- Agent and human actions update the same visible state through one controller.
- Dynamic registration changes with workflow state; compatibility mode remains safe.
- A plan mutation invalidates prior authorization.
- Human authorization makes execution available without exposing an authorization tool.
- Repeated execution returns the original confirmation receipt.
- First-run guidance uses the real workflow and retires after diagnosis.
- Product language precedes exact protocol evidence in every workflow state.
- Revert never restores prior authorization.

## Edge Cases

- WebMCP unavailable or registration rejected.
- Empty, extra, mistyped, overlong, stale, and unknown inputs.
- Double-click, double tool invocation, slow network, navigation during work.
- Expired authorization, changed plan, inventory conflict, and storage failure.
- Lost execution response followed by receipt recovery.
- Process restart with draft, authorization, and completed receipt state.
- Narrow viewport, keyboard operation, and reduced-motion preference.
- Two-tab conflicts, cancellation races, 200% zoom, long copy, and live-region priority.

## Critical Path

Open the deployed app, diagnose the conflict through ChatGPT, compare repairs,
select the arrival-safe option, prepare review, change the plan to prove stale-state
rejection, authorize the exact replacement plan through the page, execute through
ChatGPT, and recover the persisted receipt after a repeated request.
